# Widget Reference

Short explanations of the Streamlit widgets and elements used in AdamFit. Page docs link here instead of repeating the explanation.

| Widget | What it does |
|--------|--------------|
| [st.set_page_config](st_set_page_config.md) | Sets the browser tab title and icon |
| [st.title](st_title.md) | Large page heading |
| [st.write](st_write.md) | Shows text or almost any value |
| [st.success / st.error](st_status_messages.md) | Green and red message boxes |
| [st.dataframe](st_dataframe.md) | Interactive table |
